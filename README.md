# Paw Patrol pet management

This application is written in Dart with Flutter.

## Project structure

```text
lib/
  main.dart
  models/pet.dart
  screens/                  One Dart widget per original page
  theme/app_theme.dart      Shared Flutter design system
  widgets/                  Navigation shell and reusable UI
```

## Run the app

1. Install Flutter and add it to your PATH.
2. Open a terminal in this folder.
3. Run `flutter pub get`.
4. Run `flutter run -d chrome` for the web version, or choose another device.
